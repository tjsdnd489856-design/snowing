# 렌즈 관리자 (Lens Manager)

렌즈 재고 및 유통기한 관리를 위한 전문 CLI/GUI 도구입니다.

## 🚀 주요 기능
- **바코드 스캔**: GS1-128 규격 바코드를 해석하여 제품명, 도수, 유통기한 자동 등록
- **재고 관리**: 제품 입고(Insert) 및 판매(Home) 처리
- **유통기한 알림**: 실시간으로 유통기한 임박 제품을 감시하고 경고 알림 제공
- **글로벌 단축키**: 어떤 창에서도 `Insert`와 `Home` 키로 즉시 작업 가능

## 🛠 최근 업데이트 (2026-02-23)
- **GUI 레이아웃 최적화**: 
    - 유통기한 안전 버튼 세로 길이 2배 확대 (가독성 향상)
    - 입고/판매 버튼 우측 열 배치로 효율적 공간 활용
- **사용자 편의성(UX) 강화**:
    - 모든 팝업 창 화면 중앙 배치 로직 적용
    - 팝업 오픈 시 입력창 자동 포커스(커서 이동) 기능 추가
- **강력한 글로벌 단축키**:
    - 다른 프로그램 사용 중에도 `Insert`, `Home` 키 즉각 반응
    - 단축키 입력 시 해당 키의 타 프로그램 전달 차단(Suppress) 및 팝업 강제 최상단 노출

## 💻 실행 방법
- GUI 모드: `run_gui.bat` 실행
- CLI 모드: `run.bat` 실행
